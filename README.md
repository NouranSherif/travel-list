# Travel List

A React app to manage your travel packing list. Built as part of **Jonas Schmedtmann's Ultimate React Course** on Udemy.

## Features

- Add items with description and quantity
- Mark items as packed/unpacked
- Delete individual items
- Clear the entire list
- Data persists in localStorage

## Live Demo

[View on Vercel](https://travel-list-react-iota.vercel.app/)

```bash
npm start
```
